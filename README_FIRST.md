# WordNest UI and animation pack

1. Unzip this into the project root, next to lib/ and pubspec.yaml. It adds design/ (Stitch screens + brand images),
   IMPLEMENTED.md and AGENT_PROMPT_ui_animation.md. Commit your current code first.
2. Open your AI agent in the project and paste the whole content of AGENT_PROMPT_ui_animation.md as ONE message.
3. When it finishes, run the app, play level 1 to the end, and check the screens in its final report.

Not included on purpose: the Missions screen (you will provide it).
