# ENABLE English word list

`enable1_3to7.txt` is the 3–7 letter, ASCII-alphabetic subset of `enable1.txt`
from [dolph/dictionary](https://github.com/dolph/dictionary), commit
`233d25a56b9ac8bef906916ccf091a976995cce0`. The source SHA-256 is
`3f16130220645692ed49c7134e24a18504c2ca55b3c012f7290e3e77c63b1a89`.
The subset contains 51,852 entries and has SHA-256
`9c2f04e69f9feb2b84511cf5e984560cb62c2a92a088e34db98b9d2f9ecce141`.

ENABLE is a public-domain word-game list; see the
[Games::Word::Wordlist::Enable documentation](https://github.com/Abigail/Games--Word--Wordlist--Enable/blob/master/README)
for its statement about the list's status. This is a word list, not a source of
word definitions. Its inclusion of a word does not guarantee that the word is
common, suitable for every audience, or spelled according to every dictionary.
